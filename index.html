Nhỏ gọn. Đủ chất Tetris.

Gameplay dùng chung cho cả hai chế độ, với dữ liệu điểm số được lưu cục bộ.

🎮 Gameplay hoàn chỉnh

7 Tetromino, xoay, collision, xóa dòng, level, combo, Ghost Piece, Hard Drop và Game Over.

📟 No-GUI

Chạy native trong Termux, không cần X11 hay desktop environment.

🖥️ GUI

Giao diện đồ họa tùy chọn với pygame-ce khi môi trường hỗ trợ.

🏆 High Score

Lưu điểm cao nhất, level, tổng số dòng và combo tốt nhất trên thiết bị.

⚙️ Điều khiển

A/D, S, W hoặc phím mũi tên, Space, P, R và Q. Không cần chuột.

🧩 Hai cách chạy

Menu cho phép chọn GUI/No-GUI, hoặc dùng tham số dòng lệnh để khởi động nhanh.

Chọn cách bạn muốn chơi

Một game engine, hai trải nghiệm.

📟 Terminal / No-GUI

Phù hợp nhất với Termux. Nhẹ, nhanh, không phụ thuộc GUI.

python tetris.py --terminal

🖥️ GUI

Cài pygame-ce rồi khởi chạy giao diện đồ họa.

pip install -r requirements.txt
python tetris.py --gui

Bắt đầu trong vài giây

Mở Termux và chạy các lệnh sau.

pkg update
pkg install python git
git clone https://github.com/khahdihdz/tetris-termux.git
cd tetris-termux
python tetris.py
